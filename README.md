# PDF (.docx) to .pptx конвертер

Работает через локальное веб-приложение, для работы нужна локально развернутая модель (через LM Studio)


## Перед работой нам надо

### 1. Установить зависимости

```
pip install -r requirements.txt
```

### 2. Скачать программу LM Studio и модель

Без этого сайт запустится, но кнопка будет выдавать ошибку

1. Скачайте LM Studio: https://lmstudio.ai
2. Установите и откройте его.
3. Во вкладке поиска моделей скачайте любую модель, которая понимает русский.
   Достаточной будет модель на 4b-8b параметров.
   Я использовал `google/gemma-3n-e4b`. можно найти похожую.
5. Перейдите во вкладку "Local Server" (находится слева) и запустите локальный сервер.
   По умолчанию сервер поднимается на `http://127.0.0.1:1234` - этот адрес уже
   указан в `llm.py`, менять ничего не надо.
6. Убедитесь, что в LM Studio модель именно загружена (не просто скачана).
