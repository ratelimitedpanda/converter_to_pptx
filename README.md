## Перед работой нам надо

### 1. Установить зависимости

```
pip install -r requirements.txt
```

### 2. Скачать программу LM Studio и модель

Без этого сайт запустится, но кнопка будет выдавать ошибку

1. Скачайте LM Studio: https://lmstudio.ai
2. Установите и откройте его.
3. Во вкладке поиска моделей скачайте любую модель, которая понимает русский.
   Достаточной будет модель на 4b-8b параметров.
   Я использовал `google/gemma-3n-e4b`, можно использовать другую.
5. Перейдите во вкладку "Local Server" (находится слева) и запустите локальный сервер.
   По умолчанию сервер поднимается на `http://127.0.0.1:1234` - этот адрес уже
   указан в `llm.py`, менять ничего не надо.
6. Убедитесь, что в LM Studio модель именно загружена (не просто скачана).

Имя модели, которое находится в LM Studio (стандартно указана `google/gemma-3n-e4b`), нужно будет
вписать в поле "Модель в LM Studio" на самом сайте.

## Как запустить

```
python app.py
```

Далее открываем приложение в браузере http://127.0.0.1:5000 
Выбираем файл, страницы для конвертации и название модели и начинаем конвертацию. 

## Что важно знать

- Работает с `.pdf` и `.docx`. Старый `.doc` не поддерживается.
- Для PDF диапазон страниц честный - берутся ровно те страницы PDF, что указаны.
- Для DOCX страницы приблизительные: Word не хранит готовую разбивку на страницы.
- Номера страниц и колонтитулы (типа "Глава 3" на каждой странице) автоматически
  вырезаются перед тем, как текст уйдёт в модель.
- Чем слабее модель в LM Studio, тем чаще она может не соблюдать формат ответа
  или сильнее резать текст - в этом случае можно попробовать модель с большим количеством параметров.

## Структура проекта

- `run.py` - запускает приложение
- `app/__init__.py` - веб-сервер на Flask, принимает файл и отдаёт готовый `.pptx`
- `app/extract.py` - достаёт текст и картинки из PDF/DOCX постранично
- `app/llm.py` - работает с языковой моделью
- `app/build_pptx.py` - собирает сами слайды
- `app/templates/index.html`, `app/static/` - веб-часть
